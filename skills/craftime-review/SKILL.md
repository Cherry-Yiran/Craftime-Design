# 检查 Craftime 设计稿

先读取并遵循 [规范使用反馈](../craftime-figma-ui/references/interaction.md)，显示“检查设计”启用提示。结束时展示带证据的检查状态，并提供查看使用情况与重新检查的入口。

先读 [基础设计规则](../craftime-figma-ui/SKILL.md)，再按本次平台、语言和目标画板执行检查。评审默认只读；用户要求修复时，仅修改其授权范围。

- 读取对应实时样式、变量、组件定义，核对目标子树。文字检查真实属性与样式引用；混合样式逐段检查。组件检查关联、来源平台与状态，不能只凭层名。
- 必须读取 [颜色用途与检查](../craftime-figma-ui/references/color-semantics.md)，将实际用途与变量语义分开核对。本次范围内的普通分隔线不能因为绑定 `border/subtle` 就判为通过；逐项读取实际模式的别名链、HEX、不透明度和厚度，执行检查脚本或等效逻辑，并报告输出。普通分隔线按2026-11-02用户最新确认使用1px、`#F2F2F2`、100%不透明，目标内可用本地`separator/default`；基础`中性/50`、骨架与禁用表面不变；明确组件特例与用户例外按来源单独报告。
- 通知模块检查未读点、数量徽标是否沿用原稿#FF2442；数字徽标为红底白字，不接受品牌橙色或Demo强调色替代。区分结构/流程参考与视觉依据；当前页选中指示线的红色不推广成全产品规则。
- 仅核对实际复用资产的来源、主组件关联和新增部分；不能仅凭外观相同宣称复用，不把未查找业务页判为偏差，不为审稿自动搜索其他业务 UI。只有用户明确要求查找时才进行相应搜索；移动端检查适用2026-10-27限定例外，可查同模块 Mobile 原稿，不扩展到无关业务或 Web。新完整页面核对导航 `1336:145424` 与顶部 `1336:144845` 是否来自用户指定文件 `RFpf6Kksqu6SFsnjxjIn5l` 并保持原样；已有页面核对固定区域是否保持基线。只有单张最终截图时不能宣称修改前后保持一致；修复授权不涵盖这些固定区域，用户明确要求修改对应区域的例外单独列出。
- 图标评审必须读取 [图标规则](../craftime-figma-ui/references/icons.md) 与机器规则；对本次新增/修改图标核对 MingCute 官网来源、真实可编辑 Stroke 与中心线路径、最终使用尺寸下1.67px及变量绑定。填充轮廓不是可调描边，缺证据标待验证；用户指定资产另记例外，未授权历史稿与固定导航/顶部不批量修改。
- 按 [四项设计决策规则](../craftime-figma-ui/references/design-decisions.md) 检查：移动端是否有同模块移动稿与正式间距来源、是否独立排布及核对热区/安全区；信息是否便于扫描、是否存在无用途分隔或重复辅助信息；关联动作图标在含义与轮廓上是否可区分；交付清单是否符合一屏/流程/全部状态范围并依据用户最新定稿，是否保留各状态差异与交互。只读评审只给结论；同步、清理或修复仍需对应任务授权。结构记录不代替这些检查，缺证据标待验证，不新增评分或审批轮次。
- 只有明确适用的规则才能判为违反规范。未定义属性、平台不适用、用户要求的例外与已确认偏差分开列。
- 在现有目标截图检查中，核对真实尺寸下的换行、裁切、溢出、对齐，并结合页面目的判断配色协调、主次、留白和视觉轻重；色值合规不等于视觉成立。范围与改动相称，复用已有截图，不另设审美轮次、评分报告或例行用户确认。仅发现可具体说明的问题才提出修正；无明确问题即完成，常规视觉取舍由助手判断，不无故扩展或反复打磨。保持默认只读；已获修复授权时只修正授权区域并核对受影响部分，不覆盖明确规范或保护区域。视觉建议与已确认规范偏差分开，不把局部偏好升为全局规则。不能仅凭元数据断言视觉通过，缺截图时标待验证。
- 每个问题给节点链接、实际值、规范值、来源和修正建议。先列影响较大的问题。
- 汇报整体状态：通过 / 有偏差 / 有例外 / 待验证。存在已核实语义选色错误时写“有偏差”，读取不全时写“待验证”。变量绑定、结构正确、截图无裁切都不能代替语义检查，也不能将局部检查升级成整页合规。工具或权限不足时只报告已验证范围。

若要求修复，修复后检查相关属性与截图；回报未解决项。不要通过修改规范源来让设计稿“通过”。



执行 [读回检查](../craftime-figma-ui/references/readback-checks.md)，报告 MCP 检查输出；缺少实时定义、截图或固定区域基线时标为待验证。字体异常按 [原生文字写回流程](../craftime-figma-ui/references/font-writeback.md) 处理，不静默替换或转曲。
