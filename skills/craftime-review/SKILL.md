# 检查 Craftime 设计稿

先读取并遵循 [规范使用反馈](../craftime-figma-ui/references/interaction.md)，显示“检查设计”启用提示。结束时展示带证据的检查状态，并提供查看使用情况与重新检查的入口。

先读 [基础设计规则](../craftime-figma-ui/SKILL.md)，再按本次平台、语言和目标画板执行检查。评审默认只读；用户要求修复时，仅修改其授权范围。

- 读取对应实时样式、变量、组件定义，核对目标子树。文字检查真实属性与样式引用；混合样式逐段检查。组件检查关联、来源平台与状态，不能只凭层名。
- 只有明确适用的规则才能判为违反规范。未定义属性、平台不适用、用户要求的例外与已确认偏差分开列。
- 查看目标截图，核对真实尺寸下的换行、裁切、溢出和对齐。不能仅凭元数据断言视觉通过。
- 每个问题给节点链接、实际值、规范值、来源和修正建议。先列影响较大的问题。
- 汇报整体状态：通过 / 有例外 / 待验证。工具或权限不足时只报告已验证范围。

若要求修复，修复后检查相关属性与截图；回报未解决项。不要通过修改规范源来让设计稿“通过”。
