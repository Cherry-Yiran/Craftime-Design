# Web 字重按用途选择 · 2026-11-02

用户明确反馈：功能文字过细，已手工加粗；通常只有昵称、帖子正文、小标签等内容文字使用常规字重。新设计必须先给文字确定用途，再选样式。默认配置见[机器规则](typography-roles.json)。本规则针对新建或本次获准修改的Web文字，不自动覆盖用户改后的稿、历史组件或移动端。

| 用途 | Craftime默认 | 边界 |
| --- | --- | --- |
| 页面标题 | 700 Bold | 分区/弹窗标题沿用现有600–700层级 |
| 导航、一级分类、Tab、筛选、表单标签、按钮、行内操作 | 600 SemiBold | 主/次按钮、未选中态也保持600；不因为灰色或未选中就换400 |
| 未读数、徽标、关键计数 | 600 SemiBold | 保持已确认字号，不用缩字解决密度 |
| 昵称、帖子/评论正文、引用、内容小标签 | 400 Regular | 允许用户指定或正文富文本的局部强调；不把现有600昵称自动改回400 |
| 时间与次要元信息、输入内容/占位和辅助说明 | 400 Regular | 必须明确是内容或元信息；可点击的筛选标签、输入框外标签不在此列 |

“小标签”指内容标签、主题词等，不是Tab或筛选按钮。不要用Body/Compact、Body/Caption等400字重样式直接制作功能文字。现有样式名或变量绑定成功不证明用途正确；若正式样式仍为旧400/500，在获准目标建立同字号、同行高的600本地功能样式并注明来源与日期，不能改共享Regular变量让正文一起变粗。

Regular=400，不使用Light300。读取真实fontWeight和可变轴wght；字体菜单写Regular时也可能是500，不能仅凭style字符串判断。混合文字逐段读回，数字不和时间/正文混为同一角色。保留现有字号、行高、颜色和间距；只有用户另行授权才迁移这些属性。已经确认的Meetup小号Cancel/Recap Regular特例继续单列，不用新默认批量覆盖旧组件。

## 参考实测与采用范围

用户指定[MakerWorld模型页](https://makerworld.com/en/models/3505604-gingerbread-man-christmas-paper-towel-holder#profileId-4005155)。2026-11-02在1440×1000桌面视口读取可见DOM计算字体并查看截图；该URL自动跳转中文路径，CSS首选Open Sans、中文实际仍可能使用系统回退。

导航14/20/600，模型标题18/24/700，作者昵称14/20/400，关注12/16/600，排序按钮14/36/600，区块标题16/24/700；正文14/20/400、内容标签14/24/400、时间14/22/400。选中详情Tab为600，未选中为400；回复与互动计数为500。这些是该页当次实测，不是Craftime直接照抄的数值。根据用户本次更强的可读性要求，Craftime功能文字与计数默认600，不采用参考页未选中Tab400、回复/数字500的较细方案。

## 设计时执行与检查

1. 在现有设计步骤中为每段文字填写semanticRole及usage.kind（heading/control/content/metadata），结合实际父级、可点击用途与截图，不仅按图层名推断。
2. 选择匹配语义的样式。功能项优先600；内容可400。用户最新手改优先，缺失的对应节点不能假装已经读取或擅自覆盖。
3. 运行既有craftime_check_design或check-design-readback.mjs；它会调用check-typography.mjs。即使actual与错误的400 expected一致，功能语义仍判有偏差；缺角色或用途证据判待验证，不能报通过。
4. 实际字重与Text Style/字号/行高对照继续保留。检查器只验证所提供记录，不能自动识别截图中的业务语义，也不保证宿主总会调用它；它不是Figma全局写入拦截器。
