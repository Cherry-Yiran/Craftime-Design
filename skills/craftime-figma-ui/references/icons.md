# 图标规则 · 2026-10-15

2026-10-15 用户确认：后续图标始终从 https://www.mingcute.com/ 选取；交付可调整粗细的原生矢量，最终使用尺寸下描边统一为 1.67px。

- 每次新增或替换先读取 [机器规则](icon-rules.json)，去官网确定官方名称，再取得对应官方SVG，记录名称、URL、版本或提交与SHA256。不能使用其他图标库作为默认回退。
- 常规选 Core Regular；保留真实原生 Stroke 与可编辑中心线路径。filled path、位图、无实际Stroke的strokeWeight不合格。源为填充轮廓时保形转换，对照官网原图；无法保真时报告限制。
- 完成最终视觉尺寸后读回实际线宽1.67px，绑定 icon/stroke-width；检查变量可调，不让实例缩放改变最终线宽。使用16/20/24等现有视觉尺寸，不拉伸。
- 颜色沿用 icon/default、禁用与激活语义，不自行新增状态。用户明确指定的特殊资产记录例外。
- 只检查或修改本次授权子树；历史资产不当成当前默认，不批量更换共享母版、导航与完整顶部。
- 交付证据包括官网来源、路径与Stroke读回、最终尺寸线宽、变量绑定及截图。未读到不能标通过。

## 语义避撞 · 2026-11-02

选型同时执行 [图标语义避撞](design-decisions.md)：明确动作或对象，与当前页面及已提供的关联图标比较含义与轮廓，在最终尺寸和实际控件中确认辨识度。来源、线宽合规不证明语义清晰；缺少对照标待验证，不自动浏览无关业务 UI。
