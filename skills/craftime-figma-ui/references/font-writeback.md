# 字体异常与原生文字写回

适用：已授权目标中的字体加载失败、旧字形缓存或原生导入显示异常。工具不能加载字体不等于用户电脑未安装字体。

1. 先读取目标实际字体、混合文字的样式分段、字重、字号、行高、字距、Text Style、变量绑定、文案及布局；保存修改前截图与节点 ID。历史稿保留原字体，只有明确授权迁移时采用新方案。
2. 优先在工具环境正常加载目标字体；失败后记录具体错误。不得静默换字体、转曲或转成图片，也不得因文字属性写入成功便宣称可见字形正确。
3. 必须使用原生导入时，用可用的真实同名字体渲染独立 HTML 文字，再通过已支持的原生导入能力生成 Figma TEXT。先验证小样，读回字体、真实字重、样式和绑定；浏览器字体回退不能算字体一致。
4. 原生导入应落在正确页面，记录新节点及临时根节点 ID。若需通过 group 保留字形缓存，节点必须在同一页面；禁止把跨页面 group 当作移动手段。布局、位置和尺寸需读回，不能仅凭成功返回值。
5. 装回目标后仍保持可编辑 TEXT。核对 characters、fontName / weight、每段样式 ID、绑定、段落、换行、裁切和实际截图；导入或自动绑定可能改变字重，不能只核对字体名称。
6. 任一步工具返回 isError 或缺少节点时停止依赖它的后续动作，先读回现场再处理。仅在目标文字装回且属性与截图核对后，删除本次生成的临时根节点；不删除未知 ID，不以清理代替恢复。
7. 输出实际完成范围和未解决项。若原生导入不可用或不能保真，保留原稿并报告限制；可继续独立工作。不得把本地字体渲染、节点写回、截图检查或 Present 交互相互替代。

依据：项目已确认的可编辑文字与字体策略；历史可行办法仍须在本次目标小样验证。此流程不授权批量迁移或修改固定导航、顶部。
